# TASKS.md

没有 JSON 工具时使用的人类可读任务单。方案 B 建议优先用 `tasks.json`（模型更不容易整段改写），本文件可作为对照清单。同一时间只认领一条主线任务。

状态只用：`todo` / `claimed` / `in_progress` / `blocked` / `done` / `rejected`。

标 `done` 的前提：验收项全部有证据，并且写明已实测或未实测。未实测的任务不得标完成。
