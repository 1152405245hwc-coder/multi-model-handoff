# 接棒开场口令

把下面整段发给任何一个新模型或新会话。不要只说“继续”。

---

请先不要改任何文件。按这个顺序只读：

1. `AGENTS.md`
2. `STATE.md`
3. `DECISIONS.md`（尤其是否决 / 负记忆区，以及「已退役规则 / Lessons Retired」）
4. `HANDOFF.md`（只把这一份当作当前现场）
5. `tasks.json` 或 `TASKS.md`（若存在）

不要把 `logs/handoff-archive/` 里的旧交接当作当前事实。需要核对历史时，可以查阅，但必须标明那是归档证据。

读完后先用五到七句话向我汇报，再等我确认后才开始动手：

- 北极星和当前阶段是什么
- 当前唯一主线任务是什么，是否已被别人认领
- 哪些路径已经被否决或退役，你不会重做
- 上一棒已完成且已实测的是什么，未实测的是什么
- `AGENTS.md` 是否看起来有过时、冲突或与现场不符的条款（只汇报，不要擅自改）
- 你准备认领哪一条任务，以及你的第一个具体动作

规则：

- 没有认领成功，就不要改文件
- 不要扩大 `STATE.md` 里的范围，不要翻案否决或退役记录
- 不要把未实测的工作标成完成
- 若发现交接文件与现场不符，先停下来告诉我，不要擅自改主线
- 未经我确认，不要改写 `AGENTS.md`
