# 交接归档

这里存放历次被替换下来的 `HANDOFF.md` 现场，作为 Trace（探索证据），不是当前真相。

## 用法

1. 交棒重写 `HANDOFF.md` **之前**，把当时的文件复制到本目录。
2. 建议命名：`YYYYMMDD-HHMM-handoff.md`，时间使用 America/Cordoba（UTC-3）。
3. 下一棒开场只以项目根目录的 `HANDOFF.md` 为当前现场。需要核对“当时为什么改向”时，再查阅本目录。
4. 不要把本目录里的旧结论写回 `AGENTS.md` 或 `STATE.md`，除非项目负责人明确恢复某条规则，并同时更新 `DECISIONS.md`。
